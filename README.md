# Three Blind Mice

You can't see. Squeak to see. A 3D stealth game for one to three mice: every sound is a ring of light that draws the
farmhouse in amber lines, and the farmer's wife hears every ring that reaches her. Steal the cheese, chain the crumbs,
tiptoe over the creaky boards, get it all home before dawn and keep your tail. Twelve nights with bronze, silver and gold
medals, a new Daily Raid every day with its own board, daily goals and a streak, a mouse that levels up and a wardrobe to
dress it. Co-op with up to three friends.

Play: https://onceworlds.com/play/three-blind-mice

## Develop

```sh
npm install
npm test        # rules, hunters, levels, whole simulated nights, the room flow
npm run build   # dist/
```

DESIGN.md has the rules, numbers and screens. CREDITS.md lists every art asset (all CC0).
