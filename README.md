# Three Blind Mice

You can't see. Squeak to see. A 3D stealth game for one to three mice: every sound is a ring of light that draws the
farmhouse in amber lines, and the farmer's wife hears every ring that reaches her. Steal the cheese, get it home before
dawn, keep your tail. Twelve nights, co-op with friends.

Play: https://onceworlds.com/play/three-blind-mice

## Develop

```sh
npm install
npm test        # rules, hunters, levels, whole simulated nights, the room flow
npm run build   # dist/
```

DESIGN.md has the rules, numbers and screens.
